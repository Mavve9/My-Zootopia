# My-Zootopia 🦁

Entwickelt im Rahmen der Umschulung zum Softwareentwickler  

---

## Was ist das?

Eine Python-Anwendung die live Tierdaten über eine externe API abruft  
und daraus automatisch eine HTML-Seite generiert.  
Eingabe: Tiername → Ausgabe: fertige Webseite mit Informationen.

---

## Was wurde gelernt

- API-Integration mit realen Schnittstellen (API Ninjas)
- Verarbeitung von JSON-Daten in Python
- Dynamische HTML-Generierung aus Code
- Fehlerbehandlung bei externen API-Aufrufen

---

## Tech Stack

- 🐍 Python
- 🌐 HTML
- 🔌 REST API (API Ninjas)
- 🔧 Git / GitHub
